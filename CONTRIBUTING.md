# Contributing corrections

Please identify the affected document and section, the exact DMWF package checksum, relevant CFG file and line, and whether your observation is static or reproduced in an application. For reproduced behaviour, include product and ProjectWise Explorer builds, relevant final variable values and a minimal test hierarchy.

Do not submit vendor archives, proprietary client datasets, project drawings, credentials or authentication tokens. Link official source material and describe the smallest reproducible configuration case.

Keep guidance in plain language and distinguish delivered behaviour from recommended operating practices. Preserve editable Mermaid source when changing a diagram and update its SVG companion and offline edition.
